# Propuesta Digital WILAR

Landing page comercial creada por FC IA Studio para presentar la propuesta digital de WILAR.

## Contenido

- `index.html`: estructura principal de la landing.
- `styles.css`: estilos responsive.
- `script.js`: animaciones y navegación.
- `assets/`: logos e imagen de referencia.
- `public/`: copia lista para Vercel como directorio de salida.
- `vercel.json`: configuración lista para Vercel.

## Subir a GitHub

1. Crear un repositorio nuevo en GitHub.
2. Subir todos los archivos de esta carpeta.
3. Verificar que `index.html` quede en la raíz del repositorio.

## Publicar en Vercel

1. Entrar a Vercel y elegir `Add New Project`.
2. Importar el repositorio de GitHub.
3. Framework Preset: `Other`.
4. Build Command: `npm run build`.
5. Output Directory: `public`.
6. Deploy.

Si Vercel muestra el error `No Output Directory named "public" found`, volver a subir esta version actualizada del proyecto, porque ya incluye la carpeta `public`.
